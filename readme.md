# Newfon\_core

Это ядро синтезатора newfon, базой для которого послужил движок ru\_TTS. Изменения по сравнению с ru\_TTS:

* Теперь голоса четыре: мужской 1, женский 1, мужской 2 и женский 2.
* Некоторая часть параметров удалена.

## Чтение чисел

Целые числа до 153 цифр включительно читаются с названиями разрядов от тысячи до новемквадрагинтиллиона (10^150). В частности, поддерживаются квадриллионы, квинтиллионы, октиллионы и единица с 50 нулями. Окончания названий согласуются с числом. Более длинные целые числа читаются по цифрам.

Отдельные последовательности из двух и более нулей и ведущие нули перед значащими цифрами читаются с подсчётом: `0000` — «четыре нуля», `0000000000` — «десять нулей», 21 ноль — «двадцать один ноль», 111 нулей — «сто одиннадцать нулей». Одиночный ноль читается как «ноль». Нули внутри числа и десятичной дроби не сворачиваются в счётчик; обработка дробей по-прежнему использует названия знаменателей до 14 знаков после разделителя.

Проверка чтения чисел без NVDA: `python -B tests/test_numerics.py` из папки ядра либо `make test`. Нужны Python 3 и C-компилятор для текущей системы (в Windows — x86_64-w64-mingw32-clang); другой компилятор можно указать переменной `CC`.

## Сборка

Здесь описывается процесс сборки движка (или ядра) вместе с дополнением, хотя библиотеку также можно собрать отдельно.

### Требования

* [llvm-mingw](https://github.com/mstorsjo/llvm-mingw) в варианте ucrt-x86\_64. Нужны   i686-w64-mingw32 и x86\_64-w64-mingw32.
* [Git for Windows](https://git-scm.com/download/win)
* [CMake](https://cmake.org/)
* [7-Zip](https://www.7-zip.org/)
* Python 3 и модуль markdown.
Ничего из перечисленного не обязано лежать в PATH. Батник сам находит llvm-mingw, CMake, 7-Zip и Git в стандартных местах установки.

### Сборка дополнения

Из корня проекта дополнения выполнить

* build.bat            собрать дополнение
* build.bat clean      удалить результаты сборки
* build.bat clean-all  то же плюс собранные зависимости (pcre2)
* build.bat pot        обновить шаблон перевода
* build.bat deps       доустановить модуль markdown для Python

Можно собрать также через make, если инструменты уже в PATH командой make.
